# Prime Factor Rings

3D Eratosthenes on rotating prime rings: each band appears with 360 integer slots; **factor lines** a×b knock out composites (a=2 red, 3 orange, 5 yellow, 7+ cyan/violet); survivors (primes, plus 1 on ring 0; skip 2/3/5) join the pole-sweep rotation and permanent overlap map.
